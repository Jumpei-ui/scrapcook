Add ScrapCook Chef's Edition subscription system - $10/month unlimited.

1. STRIPE SETUP (Backend needs):

Add env vars in Replit Secrets:
STRIPE_SECRET_KEY = sk_live_...
STRIPE_WEBHOOK_SECRET = whsec_...
STRIPE_PRICE_ID = price_... ($10 monthly)

Install: npm install stripe

Create 3 endpoints:

POST /api/create-checkout
- Creates Stripe checkout session for price STRIPE_PRICE_ID
- mode: 'subscription'
- success_url: [yourdomain.com/success?session_id={CHECKOUT_SESSION_ID}](http://yourdomain.com/success?session_id=%7BCHECKOUT_SESSION_ID%7D)
- cancel_url: [yourdomain.com/](http://yourdomain.com/)
- return { url: session.url }

POST /api/webhook
- Verifies stripe signature with STRIPE_WEBHOOK_SECRET
- On checkout.session.completed or invoice.paid:
  Save to subscribers.json / DB: { email, customerId, active: true, expiresAt }
- On customer.subscription.deleted:
  Set active: false

GET /api/subscription-status?email=xxx
- Checks if user is Chef's Edition, returns { isPro: true/false }
