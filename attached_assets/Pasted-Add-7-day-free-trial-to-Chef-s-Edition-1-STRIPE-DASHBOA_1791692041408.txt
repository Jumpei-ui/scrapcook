Add 7-day free trial to Chef's Edition.

1. STRIPE DASHBOARD - Update your product:

Go to Stripe Dashboard -> Products -> Chef's Edition Price
Edit -> Add free trial -> 7 days -> Save
Copy new Price ID if it changed, update STRIPE_PRICE_ID in Replit Secrets

OR do it in code (better - no dashboard change needed):

In POST /api/create-checkout, add to session creation:

const session = await stripe.checkout.sessions.create({
  mode: 'subscription',
  line_items: [{ price: process.env.STRIPE_PRICE_ID, quantity: 1 }],
  subscription_data: {
    trial_period_days: 7,
    trial_settings: {
      end_behavior: { missing_payment_method: 'cancel' }
    }
  },
  payment_method_collection: 'if_required', // don't ask card until trial ends? Set to 'always' if you want card upfront
  success_url:...,
  cancel_url:...,
});

Set to:
- payment_method_collection: 'always' = they enter card now, charged after 7 days (converts better)
- payment_method_collection: 'if_required' = no card needed for trial (more signups, less conversions)

Recommended: Use 'always' for $10 product.

In /api/webhook, handle trial correctly:

If event.type === 'checkout.session.completed':
  trial_end = subscription.trial_end * 1000

If event.type === 'customer.subscription.trial_will_end':
  (Stripe sends 3 days before) - you can send reminder email later if you add email

If invoice.paid after trial -> isTrial: false, active: true
